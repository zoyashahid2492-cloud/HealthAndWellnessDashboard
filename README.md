
  # Small Wonders

  The playable game lives in [`small-wonders/`](small-wonders/README.md).

  ```bash
  cd small-wonders
  npm install
  npm run dev
  ```

  From the repository root you can also run `npm run game` and `npm run game:build` after dependencies are installed in `small-wonders/`.

  # Health and Wellness Dashboard

  This is a code bundle for Health and Wellness Dashboard. The original project is available at https://www.figma.com/design/0u7MBxIQmWffRZq5ubseeG/Health-and-Wellness-Dashboard.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
